Required Markdown Question Format

Your Markdown file must follow the standard block format below. Each question block starts with ### <number>. <Title> followed by the specific keywords:

  • ### 1. Title — Question header divider line.
  • **Question:** — Full question statement text.
  • - Option text — Answer choices listed as unordered bullet points (starts with - ).
  • **Correct Answer:** — Text matching the correct option(s).
  • **Why Correct:** — Explanation text for correct answers.
  • **Why Wrong:** — Explanation text for incorrect options / distractor notes.
Format Example 1: Single Choice Question
### 1. Hardware Device for Data Encryption for Compliance **Question:** Due to regulatory and compliance reasons, an organization is supposed to use a hardware device for any data encryption operations in the cloud. Which AWS service can be used to meet this compliance requirement? - AWS Key Management Service (AWS KMS) - AWS CloudHSM - AWS Secrets Manager - AWS Certificate Manager **Correct Answer:** AWS CloudHSM **Why Correct:** CloudHSM provides single-tenant, dedicated FIPS 140-2 Level 3 validated Hardware Security Modules (HSMs) inside your VPC. **Why Wrong:** KMS is multi-tenant/shared. Secrets Manager stores secrets. Certificate Manager manages SSL certificates.
Format Example 2: Multiple Choice Question (Select Two)
### 2. Services with Data Encryption Automatically Enabled (Select Two) **Question:** Which of the following AWS services have data encryption automatically enabled? (Select two) - AWS Storage Gateway - Amazon Elastic File System (Amazon EFS) - Amazon S3 Glacier - Amazon Elastic Block Store (Amazon EBS) **Correct Answer:** - AWS Storage Gateway - Amazon S3 Glacier **Why Correct:** All data written to Storage Gateway and S3 Glacier is automatically encrypted at rest with AES-256. **Why Wrong:** EBS and EFS require manually enabling encryption at creation.
