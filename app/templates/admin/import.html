The parser processes files containing questions separated by ### <number>. <Title> blocks. Both the Modern Structured Format (recommended) and Standard Format are fully supported.

Tag / Element Syntax Example Description
### <num>. <Title> ### 1. CloudHSM Compliance Starts a new question block and sets the title.
**Domain:** (Optional) **Domain:** `Security & Compliance` Assigns official AWS exam domain. Falls back to default.
**Type:** (Optional) **Type:** `Single Choice` or `Multiple Choice` Explicitly specifies single or multi-select.
**Question:** **Question:** Due to regulatory reasons... The question prompt text (can use blockquotes >).
**Options:** - **[A]** AWS KMS
- **[B]** AWS CloudHSM		 Answer choices starting with - (with or without [A] labels).
**Correct Answer:** - **[B] AWS CloudHSM** The text or label of the correct option(s).
**Why Correct:** CloudHSM provides dedicated single-tenant HSMs... Detailed architectural rationale for why the answer is correct.
**Why Others Are Incorrect:** - **AWS KMS:** Multi-tenant shared hardware. Distractor explanations for wrong options.
Recommended Structured Format (Single Choice)
### 1. Dedicated Hardware Encryption for Compliance **Domain:** `Security & Compliance` | **Type:** `Single Choice` | **Difficulty:** `Medium` **Question:** > Due to regulatory and compliance reasons, an organization is supposed to use a hardware device for any data encryption operations in the cloud. Which AWS service can be used to meet this compliance requirement? **Options:** - **[A]** AWS Key Management Service (AWS KMS) - **[B]** AWS CloudHSM - **[C]** AWS Secrets Manager - **[D]** AWS Certificate Manager **Correct Answer:** - **[B] AWS CloudHSM** **Why Correct:** CloudHSM provides single-tenant, dedicated FIPS 140-2 Level 3 validated Hardware Security Modules (HSMs) inside your VPC. **Why Others Are Incorrect:** - **AWS KMS:** Multi-tenant shared hardware managed by AWS. - **AWS Secrets Manager:** Stores credentials and secrets, not dedicated hardware encryption. - **AWS Certificate Manager:** Provisions and manages SSL/TLS certificates.
Recommended Structured Format (Multi-Select)
### 2. Services with Default Encryption (Select Two) **Domain:** `Security & Compliance` | **Type:** `Multiple Choice (Select Two)` | **Difficulty:** `Medium` **Question:** > Which of the following AWS services have data encryption automatically enabled? (Select two) **Options:** - **[A]** Amazon Elastic Block Store (Amazon EBS) - **[B]** AWS Storage Gateway - **[C]** Amazon Elastic File System (Amazon EFS) - **[D]** Amazon S3 Glacier **Correct Answer:** - **[B] AWS Storage Gateway** - **[D] Amazon S3 Glacier** **Why Correct:** All data written to Storage Gateway and S3 Glacier is automatically encrypted at rest with AES-256. **Why Others Are Incorrect:** EBS and EFS require manually enabling encryption at creation or via account-level defaults.
